The final source code for our research paper with my colleagues.
It contains three folders with a summary of what we have already done in the research.
Basically, our main purpose was to show whether the dynamic image approach could give the best performance compared with three different approaches:
1. Video-Based Classification:
   The configuration is a bit different from static and dynamic, because the input should be a video and needs some reconfiguration for each model
2. Static Image Classification
   Use the same models as the dynamic image approach; the difference is only in the dataset
4. Dynamic Image Classification:
   The data need to be converted first to the dynamic image shape, then implemented into the models

   Summary:
   In terms of accuracy:
   1. Video-Based
   2. Dynamic Image
   3. Static Image
    
   In terms of memory usage:
   1. Dynamic Image
   2. Video-Based
   3. Static Image
   
   In terms of processing time:
   1. Static Image
   2. Dynamic Image
   3. Video-Based
